# Revamped Portfolio 🚀

A premium, high-performance portfolio built with the modern industry-standard stack.

## 🛠 Tech Stack
- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## ✨ Features
- **Modern Aesthetic**: Dark mode, glassmorphism, and premium typography.
- **Dynamic Animations**: Smooth scroll reveals, hover effects, and interactive elements.
- **Component-Based**: Clean, reusable React components in TSX.
- **High Performance**: Sub-second load times powered by Vite.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.

## 🚀 Getting Started
1. `npm install`
2. `npm run dev`

## 📂 Structure
- `/src/App.tsx`: Main application entry and layout.
- `/src/lib/utils.ts`: Utility functions (e.g., `cn` for Tailwind).
- `/src/index.css`: Global styles and Tailwind configuration.
- `/legacy_flask/`: Original Flask codebase (for reference).
